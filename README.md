# Chenqinghe Tap

## How do I install these formulae?

`brew install chenqinghe/tap/<formula>`

Or `brew tap chenqinghe/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "chenqinghe/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
